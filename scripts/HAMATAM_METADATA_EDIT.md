# HAMATAM 動画メタデータ編集ガイド

手動アップロード後、YouTube Studio で各動画の情報を以下に合わせて編集してください。

チャンネル: https://www.youtube.com/@hamatam2006

## チャンネル設定（1回だけ）

YouTube Studio → **カスタマイズ** → **基本情報**

### チャンネル説明（コピペ）

```
田村 洸樹（HAMATAM / はまたむ）のギター演奏アーカイブチャンネルです。

DEPAPEPE のカバー、ストリートライブ、ライブハウス出演などの録画を再公開しています。
旧チャンネル @hamatam の動画をバックアップから復元したものです。

▶ 演奏者: 田村 洸樹（HAMATAM）
▶ ジャンル: アコースティックギター / DEPAPEPE
▶ お問い合わせ: hamatam2006@gmail.com
```

### おすすめプレイリスト（任意）

- **名古屋栄タイトロープ** (4本)
- **DEPAPEPE カバー** (13本)
- **ライブ・イベント** (6本)
- **ライオンズクラブ / スピーチ（限定公開推奨）** (5本)

## 各動画の編集手順

1. YouTube Studio → **コンテンツ**
2. 動画を選択 → **詳細**
3. 下表の **タイトル・説明・タグ** をコピペ
4. **カテゴリ**: 音楽
5. **子供向け**: いいえ
6. **公開設定**: 表の推奨値

> 手動アップロード時にタイトルが「2026年9月6日」など日付だけになっている場合、
> Drive のファイル名または下表の **元ファイル名** と照合してください。
