## 3. YUCHA コメントの分析（eid 200, 2008-10-27）

### コメントの流れ

1. **ひろえ**（2008/10/29）: 「ゆちやの言い付けどおり」「ゆちやお疲れなんやで」「ゆっくり休みなねーい★」
2. **【ひろな】**（スレッド見出し）
3. **YUCHA**（2008/11/01）:
   - 「さんきゅ(∀)笑」
   - 「は〜い★ 休みま〜す♪」
   - 「来てくれてホントありがとね!! またぜひ来てください∩^ω^∩」

### 解釈

- ひろえは **ゆちや（YUKARI）** に休息を勧めている。
- 直後の **YUCHA** の返信は、ファンへのお礼と「休みます」という**当事者（Vo）の返事**と読むのが自然。
- jugem サイドバーの「YUCHA (11/01)」は、**直近コメントの表示**であり、21件の独立コメントリストではない（corpus2 全文検索で **YUCHA 署名コメントは1件**）。

### 愛称の変種

| 表記 | 文脈 |
|------|------|
| ゆちや | ファン（ひろえ）→ YUKARI |
| ゆちゃ? | ファン（ひろな）の署名（HAPPY NEW ROCK 記事） |
| YUCHA | jugem コメント欄ハンドル |
| Yucha / ゆちゃ | 恋愛未満・Ameba |
